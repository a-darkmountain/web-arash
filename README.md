# وبسایت شخصی آرش یزدانیان

سلام! این ریپازیتوری شامل **وبسایت شخصی من، آرش یزدانیان** است.  
تمرکز سایت روی **امنیت سایبری، برنامه‌نویسی و نمونه کارهای شخصی** می‌باشد و با هدف نمایش حرفه‌ای توانایی‌ها و مهارت‌های من ساخته شده است.

---


- `index.html` : فایل اصلی HTML که صفحات و بخش‌های سایت را مدیریت می‌کند.  
- `style.css` : شامل تمام استایل‌های سایت و رنگ‌بندی‌ها، فونت‌ها و طراحی مدرن.  
- `script.js` : انیمیشن‌ها، تعاملات کاربر و کنترل AOS برای افکت‌های حرکتی.  
- `project/` : پروژه‌ها و ابزارهای اضافی که در سایت به نمایش گذاشته می‌شوند.  
- `assets/` : تصاویر، SVG ها و لوگوها که در بخش‌های مختلف سایت استفاده شده‌اند.

---

## 🎨 طراحی و استایل‌ها
- **رنگ‌بندی:** طیف رنگی آبی و سبز یشمی برای جلوه مدرن و مینیمال.  
- **فونت:** فونت‌های فارسی خوانا برای بخش متن‌ها و فونت مناسب انگلیسی برای کدها.  
- **انیمیشن‌ها:** استفاده از **AOS Library** برای افکت‌های حرکتی جذاب هنگام اسکرول.  
- **چیدمان عناصر:**  
  - هدر: لوگوی متنی با حرف "A" انگلیسی در وسط و لینک‌های بخش‌ها دو طرف.  
  - بخش "درباره من": متن با فونت فارسی و SVG مرتبط با شخصیت و مهارت‌ها.  
  - بخش "مهارت‌های من": هر مهارت دارای SVG مخصوص و توضیحات حرفه‌ای.  
  - بخش "نمونه کارها": پروژه‌ها با تصویر و توضیح مختصر.  
  - بخش "ارتباط با من": فرم و اطلاعات تماس مرتب و قابل استفاده.

---

## 🚀 ویژگی‌ها
- طراحی **ریسپانسیو** برای موبایل و دسکتاپ.  
- استفاده از **SVG و تصاویر برداری** برای کیفیت بالا.  
- تمامی مسیرها و فایل‌ها **نسبی به index.html** هستند، بنابراین سایت آماده GitHub Pages است.  
- همه بخش‌ها و عناصر با HTML5, CSS3 و JavaScript استاندارد ساخته شده‌اند.
